# 資料夾與文件說明

## 設計原則

Repo 根目錄就是未來 Unity 專案根目錄。遊戲資產集中於 Assets/_Project，教學與規格放在 docs；先建資料夾，不強迫同學一開始使用複雜架構。英文路徑方便程式、跨平台與 AI 使用；說明使用繁體中文。

## 根目錄

| 路徑 | 意義與使用方式 |
| --- | --- |
| README.md | 同學第一個閱讀的入口：版本、啟動方式、文件索引。 |
| AGENTS.md | AI 的共同規範與版本限制；不是會自動執行的程式。 |
| Assets | Unity 匯入的遊戲資產；資產及其 .meta 一起提交。 |
| Packages | Unity 套件清單與鎖定版本；初始化後提交 manifest.json 和 packages-lock.json。 |
| ProjectSettings | Unity 專案設定；由指定 Editor 產生並提交。 |
| docs | 設計、課程、任務、決策與驗證紀錄。 |
| tools | 專案外部輔助工具；目前空白，日後有需求再加入。 |
| Builds | 本地建置輸出；不進 Git，空資料夾不會被 Git 保留。 |
| .github | GitHub Issue 與 PR 範本；不是 AI 專屬設定。 |
| .gitignore | 排除可重新生成的快取、建置與私密檔案。 |
| .gitattributes | 文字檔換行與 Unity YAML 差異比較設定。 |

## Assets/_Project 內部

| 路徑 | 放什麼 |
| --- | --- |
| Scenes | 場景：Main、各堂課的示範場景。 |
| Scripts/Runtime/Core | 遊戲流程、分數與狀態等共用邏輯。 |
| Scripts/Runtime/Gameplay | 玩家、敵人與關卡互動。 |
| Scripts/Runtime/Input | 新版 Input System 的輸入轉接。 |
| Scripts/Runtime/UI | 介面顯示與按鈕互動。 |
| Scripts/Editor | 只在 Unity Editor 執行的工具。 |
| Prefabs | 可重用物件，例如玩家、敵人與按鈕。 |
| Art/Sprites | 依 2D 角色／物件建立資料夾（如 `Sprites/Cat2D/`），Sprite、Sprite Sheet、`.anim`、`.controller` 可放同層。 |
| Art/Models | 3D 模型，依單一模型建立資料夾（如 `Models/Cat/`），FBX、專屬 Material、Texture 同層放置，不再建立 Cat/Materials 或 Cat/Textures 子層。 |
| Art/Materials | **共用**材質，例如多個物件使用的球體顏色材質；模型專屬 `.mat` 則留在 `Models/模型名稱/`。 |
| Art/Textures | 貼圖。 |
| Art/Animations | 動畫與 Animator Controller。 |
| Audio/Music | 背景音樂。 |
| Audio/SFX | 音效。 |
| UI | 字型、介面圖片與其他 UI 資產。 |
| Input | GameInput.inputactions 等輸入動作資產。 |
| Data | ScriptableObject 設定資產。 |
| Settings | 渲染管線與其他專案設定資產。 |
| Tests/EditMode | 純邏輯與 Editor 測試。 |
| Tests/PlayMode | 場景執行與互動測試。 |

`Assets/ThirdParty` 收納外部素材與套件資產；有些套件固定自己的路徑，遵循其匯入方式即可，不要為了分類破壞套件。

## 空資料夾與 .meta

Git 不保存空資料夾，所以骨架用 `.gitkeep` 保留；它不含遊戲功能。Unity 開啟後會生成資產與資料夾的 .meta，第一次匯入後必須提交。不要忽略所有 .meta，也不要複製快取 Library。刪除或移動資產時，要一併維護 .meta。

目前不預建 Resources、Addressables、網路或存檔系統；課程真的需要時再增加。Tests 資料夾只是預留位置，並不代表已有可執行測試。

## 3D／2D 資產擺放範例（課程 v0.2）

```text
Assets/_Project/Art/
├── Models/
│   └── Cat/
│       ├── Cat.fbx
│       ├── Cat_Body.mat
│       └── Cat_BaseColor.png
├── Sprites/
│   └── Cat2D/
│       ├── Cat_Idle.png
│       ├── Cat_Walk.anim
│       └── Cat.controller
└── Materials/
    └── M_SharedBlue.mat
```

以上模型、貼圖、動畫與材質**只是路徑示意，ZIP 目前僅用 `.gitkeep` 預留 `Cat/`、`Cat2D/`，沒有提供實際美術素材**。
既有 `Art/Animations/`、`Art/Textures/` 暫時保留以免破壞舊的分類習慣；模型專屬資產優先放該模型資料夾，共用資產才集中管理。不要為了整理而移動第三方套件所需的相依檔案。

本週 Roll a Ball 使用 Unity 內建 Sphere、Plane、Cube，不需外部模型。練習操作 Step 1–5 以教師錄影／示範為主；AI 可輔助解釋程式與除錯，不是完成練習的必要條件。
